# Vehicle Management API

A comprehensive REST API for vehicle management, valuation, inspections, and marketplace operations.

## 🚗 Features
- User Authentication & Registration
- Vehicle Registration & Intelligence
- Valuation & Mileage Tracking
- M-Pesa Payment Integration
- Inspection Scheduling
- AI-Powered Damage Detection & Valuation
- Fleet & Insurance Dashboards
- Marketplace Listing & Financing

## 🔧 Tech Stack
- Node.js / Express (or Python/Django)
- MongoDB / PostgreSQL
- JWT Authentication
- M-Pesa API Integration
- AI/ML for valuations

## 🚀 Quick Start

### Prerequisites
- Node.js v16+
- MongoDB
- M-Pesa API credentials (sandbox/production)

### Installation
```bash
git clone https://github.com/yourusername/vehicle-api.git
cd vehicle-api
npm install
cp .env.example .env
# Update .env with your credentials
npm run dev
